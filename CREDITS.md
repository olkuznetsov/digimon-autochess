# Credits

## 3D models

All Digimon models are ripped from Bandai games (primarily *Digimon Story: Cyber Sleuth* /
*Digimon Linkz*), with skeletal animations preserved. Sources:

- **Agumon** — "Digimon Linkz - Agumon" (https://skfb.ly/6t96P) by **akennedy007** on
  Sketchfab, licensed [CC Attribution](http://creativecommons.org/licenses/by/4.0/).
- **Most of the roster** (Greymon, WarGreymon, BlitzGreymon, Gabumon, Garurumon,
  MetalGarurumon, CresGarurumon, DemiDevimon, SkullSatamon, Beelzemon, Hagurumon,
  Guardromon, Machinedramon, Patamon, Angemon, MagnaAngemon, Dracomon, Coredramon,
  Breakdramon, Keramon, Infermon, Diaboromon, Candlemon, Meramon, Gankoomon, Palmon,
  Togemon, Rosemon, Rosemon BM, Gomamon, Ikkakumon, Vikemon, Veemon, Paildramon,
  Imperialdramon, Wormmon, Stingmon, BanchoStingmon, Guilmon, Growlmon, Gallantmon,
  Dorumon, Dorugamon, Alphamon, Flamemon, Aldamon, Susanoomon, ZeedMillenniummon,
  Gracenovamon, Apollomon, Mitamamon, Coronamon, Herissmon, Tapirmon, Filmon, Piximon,
  Rasenmon) — obtained via the open-source
  [PiSuGames/DigiChess](https://github.com/PiSuGames/DigiChess) Unity project
  (assets credited there to asoliddev's Auto Chess template collection).
- **ExVeemon** — obtained via the open-source
  [elondogemoon/letsgoDigimon](https://github.com/elondogemoon/letsgoDigimon) Unity project.

All converted .fbx→.glb with assimp (`scripts/convert_model.py`), animations preserved.
